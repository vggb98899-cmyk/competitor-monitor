# 竞品数据采集系统 — 一看就懂的流程图

```
┌────────────────────────────────────────────────────────────────────┐
│                    每天早上8点（自动运行）                           │
│                                                                     │
│  ① 拉数据                                                           │
│     main.py  -->  Naturehike/products.json                          │
│                -->  Snow Peak/products.json                         │
│                -->  凯乐石/products.json                             │
│                  ↓                                                  │
│               拿到3家店铺全部商品（标题/价格/品类/库存状态）             │
│                                                                     │
│  ② 爬评分                                                           │
│     对每家店铺的前20个商品，逐个访问商品详情页                          │
│     从页面HTML里搜 "ratingValue" 提取评分                             │
│                  ↓                                                  │
│               拿到评分数据                                            │
│                                                                     │
│  ③ 算变化                                                           │
│     读价格历史 → 跟昨天比 → 算出"涨了/跌了/没变"                      │
│     读评分历史 → 取最近7天 → 算出"评分趋势"                           │
│     读新品记录 → 第一次出现的商品 → 记下"首次发现时间"                  │
│                  ↓                                                  │
│               所有数据汇总完毕                                        │
│                                                                     │
│  ④ 存Excel + 推钉钉                                                 │
│     生成 竞品分析日报.xlsx  →  钉钉群弹出"📥下载报表"按钮              │
│                  ↓                                                  │
│               领导点击 → 直接下载Excel                               │
└────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────┐
│ 面试时可以说的四句话                                                  │
│                                                                     │
│  Q：这个项目是做什么的？                                              │
│  A：采集Naturehike、Snow Peak、凯乐石三家户外品牌的商品数据，           │
│     每天自动出报表推送到钉钉群，监控价格变化和评分趋势。                 │
│                                                                     │
│  Q：怎么拿到数据的？                                                 │
│  A：Shopify店铺都有公开JSON接口，地址加 /products.json 就能拿全部商品。  │
│     但大牌网站有反爬，普通的Python库会被拦，                           │
│     我用 curl_cffi 模拟Chrome浏览器指纹绕过检测。                      │
│                                                                     │
│  Q：除了价格还采集了什么？                                            │
│  A：商品状态（在售/售罄）、评分、评分7天趋势、新品首次发现时间。          │
│     评分是从商品详情页HTML里提取的。                                   │
│                                                                     │
│  Q：每天怎么自动跑的？                                               │
│  A：Windows定时任务，早上8点自动运行，生成Excel，                      │
│     通过钉钉群机器人Webhook发卡片消息，领导点按钮直接下载。              │
└────────────────────────────────────────────────────────────────────┘
```
