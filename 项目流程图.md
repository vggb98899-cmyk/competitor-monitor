# Manduka 商品数据采集系统 — 一看就懂的流程图

```
┌─────────────────────────────────────────────────────────────────┐
│                   你每天早上8点（自动运行）                        │
│                                                                 │
│  ① 拿数据                                                        │
│     crawler.py  -->  manduka.com/collections/all/products.json  │
│                       ↓                                         │
│                     拿到100个商品的原始数据（标题/价格/品类）       │
│                                                                 │
│  ② 筛选                                                          │
│     遍历100个商品 → 标题含"yoga mat"的留下 → 其他跳过             │
│                      ↓                                         │
│                     筛出27个商品                                  │
│                                                                 │
│  ③ 存Excel                                                      │
│     新建Excel → 写表头（标题|品类|价格|涨跌额）→ 填27行数据        │
│                      ↓                                         │
│             output/manduka_products.xlsx                        │
│                                                                 │
│  ④ 推送到钉钉                                                    │
│     dingtalk_notify.py  →  钉钉群弹出"📥下载报表"按钮             │
│                      ↓                                         │
│                     领导点击 → 直接下载Excel                      │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 四个核心文件（其他你不用管）                                       │
│                                                                 │
│  crawler.py  →  ①拿数据  （不用打开）                             │
│  utils.py    →  ③存Excel （不用打开）                             │
│  dingtalk_notify.py →  ④推钉钉（不用打开）                        │
│  config.py   →  改关键词、改店铺URL来这里（唯一需要你碰的文件）     │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 面试时可以说的三句话                                               │
│                                                                 │
│  Q：怎么拿到Manduka数据的？                                       │
│  A：Shopify店铺都有公开JSON接口，网址加/products.json就能拿全部数据 │
│                                                                 │
│  Q：怎么筛选的？                                                  │
│  A：遍历商品标题，包含关键词的就留下，不包含的跳过                   │
│                                                                 │
│  Q：怎么推送到钉钉的？                                            │
│  A：用钉钉群机器人Webhook发卡片消息，领导点按钮直接下载Excel        │
└─────────────────────────────────────────────────────────────────┘
```
